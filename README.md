# bili-view-filter

B站 增强油猴脚本（Tampermonkey）：**UP主备注** + 视频筛选 + 链接批量提取。

- **UP主备注**（全站生效，官方没有的功能）：给任意页面看到的 UP主 起自己的备注名，备注一次，
  之后**全站任何地方**看到这个 UP主 都显示你的备注名，并用你选的颜色区分；原昵称悬停可见。
- **视频筛选**（搜索页 / UP主投稿页）：按「播放量」「UP主名字」「标题关键词」筛选，自动隐藏不匹配的卡片。
- **链接批量提取**：一键跨页采集筛选结果的链接，按 BV 去重，支持复制 / 导出 TXT / 导出 CSV。

## 功能

### UP主备注（全站）

- 在**任何** B站 页面，UP主 名字旁边都有一个淡淡的「**＋**」，点它就能备注
- 备注名 + 颜色都可以自定义（8 个预设色 + 取色器自定义）
- 备注以 UP主 的 mid 为键保存，所以**备注一次，全站生效**：首页推荐、搜索结果、视频页、
  相关推荐、空间页顶部、播放器结束推荐位…凡是出现这个 UP主 的地方都会显示你的备注名
- 已备注的显示「**✎**」，点它可以改名、换色或删除；删除后立刻还原成官方昵称
- 原昵称不会丢：鼠标悬停在备注名上就能看到「原昵称：xxx」
- 备注只存在你自己浏览器里（`GM_setValue`），不会影响账号，也不会上传
- 搜索/投稿页的面板里能看到**备注清单**（原名 → 备注名），可逐条删除，也能导出/导入 JSON 备份

### 视频筛选（搜索页 / 投稿页）

- **播放量筛选**：`播放量 ≥ N`，自动识别 `4376` / `1.2万` / `4733万` / `1.1亿` 等格式
- **UP主筛选**：精确匹配 UP主 名字，支持多个（逗号分隔），可选「模糊匹配（包含）」；
  **原昵称和你的备注名都能匹配**
- **标题筛选**：标题包含关键词，支持多个（逗号分隔，需全部命中）
- **三个条件任意留空**：留空即不按该条件过滤
- **自动隐藏不匹配**：命中的卡片打绿色「✔ 命中」角标，其余隐藏；可关闭隐藏只做标记
- **一键采集全部链接**：自动翻页、跨页按 BV 去重、可设置页数（`0` = 全部）、可中途停止，
  结果支持复制 / 导出 TXT / 导出 CSV（含标题、UP主、播放量）
- 面板可拖拽、可折叠，配置本地持久化

## 支持的页面

| 功能 | 生效范围 |
|---|---|
| UP主备注 | **全部** `*.bilibili.com` 页面 |
| 视频筛选 / 链接提取 | `https://search.bilibili.com/*`、`https://space.bilibili.com/{mid}/video`、`/upload/video` |

## 安装

1. 浏览器安装 [Tampermonkey](https://www.tampermonkey.net/) 扩展
2. 安装脚本，任选一种：
   - 直接打开安装地址（Tampermonkey 会自动识别并弹出安装页）：
     `https://raw.githubusercontent.com/fz999999/bili-view-filter/main/bili-search-filter.user.js`
   - 国内网络打不开 raw 的话，走加速镜像：
     `https://ghproxy.net/https://raw.githubusercontent.com/fz999999/bili-view-filter/main/bili-search-filter.user.js`
   - 或手动：Tampermonkey → 添加新脚本 → 把 `bili-search-filter.user.js` 全文粘贴进去 → Ctrl+S

## 使用

### 一、给 UP主 备注（全站可用）

1. 打开**任何** B站 页面（首页 / 搜索 / 视频页 / 空间页 / 动态…）
2. 把鼠标移到 UP主 名字旁边，会看到一个淡淡的「**＋**」，点它
3. 在弹出的浮层里填**备注名**、选个**颜色**，点保存
4. 之后**全站任何位置**看到这个 UP主，都会显示你的备注名（带你的颜色、加粗）
5. 想改：点「**✎**」重新编辑；想还原：点「✎」→ **删除备注**，立刻恢复官方昵称

> 备注名只是本地显示替换，**不会修改 B站 账号数据**，也不影响原昵称（悬停可见）。
> 备注清单在搜索页/投稿页的面板底部，可逐条删除，也能导出 JSON 备份 / 导入到别的浏览器。

### 二、筛选视频 + 批量提取链接（搜索页 / 投稿页）

1. 打开 B站 搜索页或某个 UP主 的投稿页，右上角会出现粉色「B站筛选器」面板
2. 填写筛选条件（任意条件都可以留空）：
   - `播放量 ≥`：例如 `1000`
   - `UP主 =`：例如 `某某UP主`（多个用逗号分隔）——填**原昵称**或**你的备注名**都能匹配
   - `标题含`：例如 `教程`（可留空）
3. 点「应用筛选」→ 不匹配的卡片会被隐藏，命中的打上「✔ 命中」角标
4. 点「一键采集全部链接」→ 自动翻页收集所有符合条件的视频链接
5. 点「复制链接」/「导出TXT」/「导出CSV」取走结果

> 提示：UP主投稿页的视频列表是**滚动后才懒加载**的。如果打开页面暂时没看到卡片，往下滚一下即可；
> 列表加载出来后面板会自动完成筛选。

## 更新记录

- **1.4.0** 新增 **UP主备注**（全站生效，官方没有的功能）
  - 扫描全站指向 `space.bilibili.com/{mid}` 的链接自动定位昵称元素，覆盖卡片作者名、
    视频页 `up-name`、推荐位 `span.name`、空间页顶部昵称等结构
  - 昵称旁「＋」即可备注（备注名 + 8 个预设色 / 自定义取色）；「✎」可改可删
  - 以 mid 为键存储，**备注一次全站生效**；原昵称保留在悬停提示中
  - 只改直接文本节点，不破坏页面结构（如 `up-name` 里的遮罩层）；Vue 重渲染改回昵称时会自动重新套用
  - 筛选读「原昵称」，且按原昵称或备注名都能匹配，两个功能互不干扰
  - 面板新增备注清单与 JSON 导出/导入；`@match` 扩大到全部 `*.bilibili.com` 页面
- **1.3.3** 修复「导出TXT / 导出CSV / 复制链接」结果不完整、或提示「没有可导出的结果」
  - 根因：导出时重新读的是**当前页 DOM**，而「一键采集」翻页后页面停在最后一页，
    于是前面几页的结果全丢（最后一页恰好 0 命中时更是完全没结果）
  - 采集时保存完整跨页结果，导出/复制优先使用它；未采集过或筛选条件已变更时回退到当前页
  - 提示文案会标注数据来源（完整采集结果 / 仅当前页）
- **1.3.2** 作者署名改为「大川」；移除仓库中的页面截图（截图中含他人页面信息）
- **1.3.1** 修复投稿页「命中 0 / 整页全隐藏」
  - 根因：脚本在 `document-idle` 执行时投稿页卡片还未渲染（懒加载），
    `detectPage()` 探测不到 `.upload-video-card` 就误用搜索页选择器 → 播放量全部读成 `NaN` → 全部判为不匹配
  - `detectPage()` 改为**优先按域名**判断页面类型，不再依赖 DOM 渲染时机
  - `applyFilter()` 每次执行都重新确认页面类型，卡片渲染完成后自动纠正
  - 标题/播放量读取增加跨布局兜底选择器；缓存签名加入页面类型，纠正后自动失效重读
  - 新增保险：设置了播放量阈值但某卡片播放量读不到时，**该卡片保留显示**（绝不整页隐藏）并给出提示
  - 播放量读不到时不再写入缓存，并每 0.5s 自动重试（上限 12 次 / 用户操作时重置），
    适配「先渲染卡片、后填播放量数字」
- **1.3.0** 三个筛选条件（播放量 / UP主 / 标题含）全部可选，任意留空即不按该条件过滤；
  播放量默认值改为留空，避免只想按 UP主/标题筛选时被默认播放量误伤
- **1.2.0** 兼容 UP主投稿页（`/video`、`/upload/video`）
- **1.1.0** 修复开启「自动隐藏」时命中卡片也被隐藏导致整页空白；新增自愈回滚、0 命中提示条、
  一键采集支持自动翻页
- **1.0.0** 首版
